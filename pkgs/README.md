# Bundled APKs

The ZIP includes **23 regular-app APKs**. They are installed after Android finishes booting; already-installed packages are skipped. The seven Fossify APKs are excluded because their LineageOS/AOSP replacements are shipped as privileged system apps. The installer pre-installs Futo Keyboard before masking Gboard and keeps Gboard if no replacement keyboard is available. PixelBoard is included as an optional keyboard and requires GMS or microG.
